# FLY CONTROL 🚁

**FLY CONTROL** is a Python-based project for controlling a DJI/Ryze Tello drone through multiple control methods.

The project includes:

* 🎮 Keyboard control
* 🎤 Voice control
* 🖥️ Terminal command control
* 📷 Live camera streaming
* 👤 Face detection
* 🎯 Object recognition with YOLO
* 🤖 Experimental autopilot
* 📊 Drone telemetry and status
* 🔧 Full Stack control system
* 📸 Screenshots and video recording
* ⚡ Emergency and motor controls

The project was started as my **first serious programming project when I was 14 years old**. It became a way for me to learn Python, robotics, computer vision, automation, and drone programming by building and testing real features.

The project supports different ways of interacting with the Tello, from simple keyboard controls to voice commands, computer vision, terminal commands, and experimental autonomous flight.

### 🛠️ Technologies

* Python
* OpenCV
* NumPy
* DJITelloPy
* EasyTello
* SpeechRecognition
* Keyboard
* YOLO
* Colorama

### 🚀 Installation

The repository includes an installer that can install the required Python modules automatically.

Run:

`install.bat`

Then launch the main project and select the control mode you want to use.

### ⚠️ Safety

This project is designed for **educational, experimental, and personal robotics use**. Always operate the drone in a safe environment and follow local laws and regulations.

This is a real software project capable of communicating with and controlling a Tello drone, but it is **not intended to be a certified commercial aviation or autonomous-flight system**.
